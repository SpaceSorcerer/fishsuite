## Changed in fishsuite, commit 608db1d (2026-09-05)

- `E:\Claude\fishsuite\src\fishsuite\report\figures.py` - The two-group imaging colour pair (WT `#595959`, QKI-KO `#D67AE5`) is now scoped to designs with TWO biological groups, so it can no longer recolour WT and QKI-KO inside a multi-group set; `group_colors(order, overrides)` takes a per-set key that beats every lock. `read_luts` now selects channel slots from the run's own `analysis_mode` instead of a fixed list: `run_config.json` always carries both `rna2_lut` and `antibody_lut`, so the old fixed list silently handed an `rna_rna` panel the antibody LUT and rendered a magenta channel green.
- `E:\Claude\fishsuite\src\fishsuite\report\peak_gate.py` - Adds `repair_pairing`. A peak floor removes partner puncta, so the run-time nearest-neighbour and paired-flag columns describe a spot set that no longer exists; they are recomputed against the surviving partner set in three dimensions with the run's voxel size. On an ungated run the recomputation reproduces the engine's own column to 1.1e-16, so it changes nothing where nothing was gated.
- `E:\Claude\fishsuite\src\fishsuite\report\aggregate.py` - Pairing endpoints are aggregated over EVERY punctum of the nucleus, nuclear and cytoplasmic, matching the engine's denominator; the pairing columns are now read from `spot_metrics.csv` rather than left out of the read list. Adds the per-channel secondary-only detection-outlier rule and the rna2 area-normalised density.
- `E:\Claude\fishsuite\src\fishsuite\report\endpoints.py` - Five rna2 endpoints added (nuclear fraction, marked PRIMARY for a two-RNA run; nuclear puncta per nucleus; area-normalised density; footprint size; above-floor intensity). The paired-fraction endpoint now states its full definition (denominator, distance, partner set) because a similarly named endpoint elsewhere is not the same quantity.
- `E:\Claude\fishsuite\src\fishsuite\report\build.py` - Clears the previous build's figures before writing, so a rebuild cannot leave orphaned panels carrying the old colours beside the new ones; records the colour key and the LUT source in `FIGURE_INDEX.md`; labels the well-level Tukey PRIMARY and the field-level one SENSITIVITY; names which endpoints are primary and why.
- `E:\Claude\fishsuite\src\fishsuite\cli.py` - Adds `--sec-outlier-k`; reads `group_colors` and `sec_outlier_k` from a run's `report_groups.yaml`.
- `E:\Claude\fishsuite\tests\test_report_peak_gate_and_pairs.py` - Seven new tests pinning each defect class: the imaging pair must not reach a five-group set, an explicit key beats every lock, LUT slots follow the analysis mode, an unknown mode draws no key rather than guessing, pairing is recomputed after a floor and is a no-op when nothing was dropped, and the secondary-only outlier rule fires per channel.
